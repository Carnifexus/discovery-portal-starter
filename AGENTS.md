# Contributor instructions

This repository is for a portable discovery application, not for client materials. Work from a fresh tree and invented examples. Never import an existing law firm's private repositories, commit history, data, credentials, or deployment settings. Use only runtime code intentionally included in this sanitized starter. Do not put them in issue reports, logs or demos. Do not send model prompts, files, or outputs that contain live case material.

The demo binds to loopback and is not production software. Do not remove that guard to make a deployment appear complete. Production requires reviewed identity, private storage, independent scanner, backups, audit access, and explicit rollout instructions. The portal must work with external AI disabled. Keep model adapters outside the client and scanner processes; content must not leave by default.

Never send, file, serve, delete records, buy services, add external users, or change sharing by default. Review provider and hosting choices with the operator before provisioning. Follow docs/BUILD-WITH-YOUR-AI.md. Ship an allowlisted archive and run the smallest test that proves a change; report what is not verified. Use reproducible releases with code, tests, instructions and synthetic fixtures only.
